TB SOFTWARE — ÍCONES DO MENU

Esta pasta contém os ícones PNG usados pela interface principal `interface_clientes.py`.

Os nomes dos ficheiros devem corresponder às chaves definidas em `MENU_ICONES` no código.
Se um ficheiro de ícone não existir, o programa mantém o botão funcional sem recuperar os símbolos antigos da interface 5.2.

Interface atual: `interface_clientes.py`.
